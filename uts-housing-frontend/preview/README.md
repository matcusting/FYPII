# 本机 Chrome 演示

这是仅供查看前端的本机演示。所有账号、房源、照片示意、评价、请求及审核记录都是虚构内容，存于 Node 进程内存；停止服务后即清空。不会发送邮件，也不会连接真实后端。请勿输入真实个人资料。

需要 Node.js 20 或更新版本。在项目目录运行：

```bash
npm ci
npm run build
node preview/demo-server.mjs
```

在同一台电脑的 Chrome 中打开 `http://127.0.0.1:4173/`。如果你收到的是已经包含 `dist/` 和 `preview/` 的演示压缩包，解压后直接在该目录运行 `node preview/demo-server.mjs` 即可，无需安装依赖。按 `Ctrl+C` 停止服务。

学生可以查看房源、收藏、咨询、室友及请求；房东可以新建示例房源，上传虚构测试文件申请身份和房屋授权审核，再提交房源；管理员可以浏览并处理审核队列。示例操作在服务运行期间保留。

演示服务支持**虚构的本机注册流程**。房东使用未用过的 `@demo.local` 邮箱、示例电话号码和密码 `Demo12345!`；新学生使用未用过的 `demo-...@student.uts.edu.my` 邮箱，例如 `demo-new@student.uts.edu.my`，并设置至少 8 个字符的演示密码。不要输入真实学校邮箱或平常使用的密码。注册后页面提供本机模拟邮箱验证链接；忘记密码与重新发送验证邮件也会显示本机模拟链接，不会发送实际邮件。学生验证邮箱后可提交两份虚构测试文件，由演示管理员审批。账号删除申请也可由演示管理员处理；仅修改内存数据，服务重启后全部恢复。

房东新增房源时填写完整地址，并选择审核通过后是否向已登录学生显示；网站不再提供 Google 地图或坐标输入。设施选项包括冰箱、热水器、衣柜、独立卫浴等。房东个人资料只需填写姓名、账号邮箱（只读）和电话号码。

学生可在账户资料中填写电话号码；住房预算、期望入住日期和偏好地点集中在室友生活习惯资料中。首页的“寻找室友”会直接打开“我的生活习惯资料”。该资料不向匹配对象显示大学信息。

可使用“待认证学生”账号或新注册的虚构学生账号演示认证流程：在个人资料页选择一张测试用学生证 JPG/PNG 图片和一份测试用录取通知书 PDF/JPG/PNG，然后由管理员在审核队列中查看申请。演示服务只检查格式，立即丢弃文件内容；管理员看到的是模拟占位图，不是真实上传文件。占位学生证上的虚构学号与虚构演示邮箱前缀一致，供管理员演示手动核对并勾选确认；这不是 OCR 或真实身份检查。请勿在演示包中提交真实证件或通知书。正式 API 会把两份文件私密保存，仅供管理员审核。

房东认证可使用“待认证房东”账号演示：先上传虚构测试身份图片，经管理员批准后，在新建房源中上传房屋授权测试文件，再由管理员批准。只有两项都在有效期内且房源地址未改变，才可提交房源审核。默认演示有效期为身份 365 天、每套房屋授权 180 天；管理员可设置更早的截止日，也可注明原因撤销批准。撤销身份会同时撤销其已批准的房屋授权并暂停房源；撤销某套房屋授权只暂停该房源。到期后房源立即从公开搜索中隐藏，房东可重新提交材料申请。房东公司、代理和转租选项需要额外的授权文件。演示服务收到文件后只验证格式并立即丢弃，管理员下载的也是模拟占位图；不要提交真实证件、产权或租约文件。

网站默认显示英文，可在导航栏切换为马来文或简体中文。聊天内容与用户填写的房源文字会保持原文。如果在另一个标签页切换账号，请刷新旧标签页后再发消息。

服务只监听 `127.0.0.1:4173`，仅供运行它的这台电脑访问。演示服务不等同于正式后端，也没有真实租房数据或业务验证。
